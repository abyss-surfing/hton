# core/src/host/publication.rs

Stable ID: `core.host-publication` · R1 · I4

`switch(app,args,ctx)` accepts optional port and `--validate-only`. R1 editable
desired YAML owns the target; the supplied port is an exact assertion of its saved
value, not a second settings writer. Reject mismatch before local consent writes;
bind the root revision again after shared effect preparation. The effects owner
resolves one public HAProxy host TCP listener, checks complete fresh host collision
evidence before consent, and uses existing public-listener approval/native admission/
apply/compensation. Unregistered holders block; this operation never stops/remaps
a discovered foreign holder. Qualified foreign remap remains a separate owner.

Validation-only and dry-run prepare under ReadOnly context and have zero writes.
Missing protected public consent is explicit ApprovalRequired; preview does not
manufacture a grant. Mutating execution returns the actual shared apply receipt,
including pending/partial/stopped state. No external DNS probe or false site/native
handshake readiness claim. Dependencies: host.effects and HostApplication.
