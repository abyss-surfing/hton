# Первый запуск HTON

Это путь первой установки HTON на сервер. Он устанавливает минимальный поддерживаемый профиль; полноценная платформа управления R1 ещё не завершена.

1. Подготовьте сервер Linux/systemd с Docker, Python 3 и PyYAML 6.x, curl, OpenSSL и системным хранилищем доверенных CA.
2. Задайте домен сайта и контактный адрес в `platform/etc/install.json` либо введите недостающие значения локально по запросу установщика. Направьте DNS на сервер и обеспечьте доступ к публичным TCP/80 и TCP/443.
3. Из checkout HTON запустите `scripts/install`. Команда сама запросит нужные права; не добавляйте перед ней `sudo`.
4. Внимательно прочитайте локальные запросы. Если обнаружен контейнер Amnezia, подтверждайте переназначение только после проверки показанной цели и параметров.
5. Прочитайте итоговый статус ready/degraded/unverified и выполните `scripts/diag`. Сохраните выданные данные подключения только по защищённому серверному пути, который показала команда.

Установщик может продолжить работу по сохранённому состоянию. Не записывайте реальные домены, данные учётных записей или DNS-секреты в публичные исходные настройки; используйте защищённую конфигурацию и хранилище секретов сервера.

Подробнее: [Настроить HTON](setup.md), [минимальная установка](../../MINIMUM-INSTALL.md) и [английское руководство первого запуска](../../1st-run.md).
