# hton — обзор проекта

hton — self-hosted-стек для недорогого VPS: один публичный HTTPS-сайт, под ним —
выбранные VPN- и прокси-сервисы и небольшая собственная control plane. Снаружи
виден обычный сайт; сервисы разделяются по TLS/SNI и секретным путям.

## Состояние

Минимальный установщик реализован; полное управление R1 ещё не завершено.
Установщик по умолчанию разворачивает текущее дерево исходников в `/opt/hton`,
готовит доверенный сайт и безопасно перемапливает подходящий существующий
Amnezia Xray.

## Быстрый старт

```sh
./scripts/hton/help
./scripts/hton/install
./scripts/hton/diag
./scripts/hton/share
```
