# Канонический CLI-контракт

Аргументы, флаги, коды завершения и совместимые имена определены только в
[CLI.md](../../../CLI.md). Не поддерживать здесь второе объявление синтаксиса.
Исторические требования сохранены в [00-decisions.md](00-decisions.md), текущие
уточнения владельца — в [OWNER-REQUIREMENTS.md](../../../OWNER-REQUIREMENTS.md).

R1: `scripts/*` вызывает Core без API daemon; `modules add/remove` меняет установленный
состав, `enable/disable` — участие в запуске. Новый модуль после add отключён;
незавершённая настройка сохраняется и продолжается повторным add. Remove сохраняет
данные, purge — отдельное явное действие, update — отдельное обновление образа.
`up` запускает сохранённый состав без обновления и перезапуска исправных членов;
`down` сохраняет запрет автозапуска и останавливает также явно связанную Amnezia.
Ошибочный desired YAML не блокирует down; up предлагает отдельный явный запуск
принятого рабочего bundle без автоматической подмены конфигурации.

Полная семантика: [lifecycle SDD](../../../specs/sdd-lifecycle.md),
[control SDD](../../../specs/sdd-control.md), [INTERFACES](../../../INTERFACES.md).
Состояние реализации: [IMPLEMENTATION-STATUS](../../../IMPLEMENTATION-STATUS.md).
