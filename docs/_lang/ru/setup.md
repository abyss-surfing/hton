# Настроить HTON

Настройка HTON подготавливает установку на сервере. Это не настройка Tartarus: Tartarus конфигурирует рабочее окружение разработки, а HTON запускается на целевом Linux-сервере.

## Перед установкой

- Нужен Linux-сервер с systemd, Docker с автозапуском, Python 3, PyYAML 6.x, curl, OpenSSL и системным хранилищем доверенных CA.
- Направьте домен сайта на сервер и откройте публичные TCP-порты 80 и 443.
- Храните DNS-учётные данные и секреты выпуска сертификата в защищённом хранилище HTON. Не помещайте их в исходный код и не отправляйте в чат.
- Проверьте домен сайта, контактный адрес и каталог установки для этой установки в `platform/etc/install.json`.

## Первая установка

Из каталога checkout HTON выполните:

```sh
scripts/install
```

Установщик сам запросит нужные системные права, локально соберёт недостающие параметры сайта и подготовит минимальный доверенный сайт и поддерживаемую интеграцию с Amnezia. Внимательно читайте каждое подтверждение. Если DNS или внешний доступ ещё не готовы, установка может завершиться со статусом непроверенной публикации; проверьте итог и диагностику, не считая сервис проверенным извне.

После установки выполните `scripts/diag`. Установка возобновляется: повторный `scripts/install` проверяет или продолжает сохранённое состояние.
