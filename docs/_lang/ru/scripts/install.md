# hton install

Устанавливает или согласует стек: при отличии разворачивает текущий исходный код, затем запускает установленный setup от root.

## Использование

```sh
./scripts/hton/install [OPTIONS]
./scripts/hton/install --help
```

Запускать из корня клонированного проекта. Основные опции: `--profile`, `--site-domain`, `--certificate-email`, `--with`/`--without`; точный список даёт `--help`. На Ubuntu/Debian отсутствующий Python 3 устанавливается через root/sudo с обычным согласием на установку пакетов до определения целевого каталога. Затем минимальный setup устанавливает остальные зависимости Python и Docker. Предпросмотр без Python завершается с инструкцией и ничего не устанавливает. Чужие контейнеры перемапливаются только после явного локального согласия.

## Платформа

Только Linux и macOS. Точка входа — Bash-скрипт; в Windows она недоступна.
