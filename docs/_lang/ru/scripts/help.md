# hton help

Печатает обзор команд или справку по одной команде.

## Использование

```sh
./scripts/hton/help
./scripts/hton/help COMMAND
./scripts/hton/<name> --help
```

Справка не имеет побочных эффектов и завершается с кодом 0.

## Платформа

Только Linux и macOS. Точка входа — Bash-скрипт; в Windows она недоступна.
