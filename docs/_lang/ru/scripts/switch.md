# hton switch

Переключает публикацию на другой публичный TLS-порт.

## Использование

```sh
./scripts/hton/switch [PORT] [--validate-only] [--json]
```

Публичный 443 и чужие ресурсы требуют точного подтверждения; переключение может разорвать клиентские сессии.

## Платформа

Только Linux и macOS. Точка входа — Bash-скрипт; в Windows она недоступна.
