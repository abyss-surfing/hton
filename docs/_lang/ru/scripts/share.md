# hton share

Печатает ссылки подключения клиентов, при необходимости в виде QR-кода.

## Использование

```sh
./scripts/hton/share [IDENTITY] [--kind KIND]... [--target TARGET] [--client CLIENT] [--format text|json|qr] [--out FILE] [--json]
```

## Платформа

Только Linux и macOS. Точка входа — Bash-скрипт; в Windows она недоступна.
