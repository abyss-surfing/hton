# hton install-unknown

Выводит руководство по ручной установке зависимостей для неподдерживаемых ОС и проверяет наличие инструментов (внутренний помощник).

## Использование

```sh
./scripts/hton/install-unknown
```

Не принимает позиционных аргументов и скрыт из публичной справки. Завершается с кодом 3, если обязательные зависимости отсутствуют.

## Платформа

Только Linux и macOS. Точка входа — Bash-скрипт; в Windows она недоступна.
