# `scripts/hton/styx-receiver`

Создаёт конфигурацию приёмника Styx HTTPS CONNECT для sing-box. Команда ничего
не запускает и не меняет текущий ingress или стенд Dokimasia.

```sh
./scripts/hton/styx-receiver \
  --spec .secrets/styx/receiver.json \
  --output .secrets/styx/receiver-sing-box.json
```

Лаунчер Tartarus вызывает проектный скрипт
[`scripts/styx-receiver`](../../../../scripts/styx-receiver); пути считаются от HTON.

Оба файла содержат учётные данные и должны храниться в секретном репозитории
HTON. Результат записывается атомарно с правами `0600`. Ошибка сохраняет
предыдущий результат и не выводит значения секретов. Входной файл должен
отличаться от выходного; предельный размер — 1 МиБ.

Формат входа и пример приведены в
[основной документации](../../../scripts/styx-receiver.md). Все показанные поля
обязательны; неизвестные поля запрещены. Имена пользователей и идентификаторы
серверов — строчные DNS-метки длиной до 63 символов. Пароли уникальны для каждого
пользователя, состоят из печатных ASCII-символов и имеют длину 16–1024 символа;
используйте случайные значения. Адреса серверов — конкретные IP, пути к
сертификату и ключу — абсолютные. Выдача и обновление сертификатов не входят в
эту команду.

D6ton внутри TLS передаёт `CONNECT vless.node-a.styx.invalid:443`; тип протокола
берётся из исходящего подключения D6ton. Клиент проходит
аутентификацию. Приёмник проверяет пользователя и разрешённый ему идентификатор,
затем пересылает TCP-поток на зарегистрированный IP/порт. Прочие назначения
отклоняются. Имя `.styx.invalid` не требует публичного DNS. Внутренние ключи,
SNI и VPN-поток не изменяются; внешний SNI общий для подключений к одному edge.

Перед запуском проверьте конфигурацию выбранным движком:

```sh
sing-box check -c .secrets/styx/receiver-sing-box.json
```

Используются поля, совместимые с sing-box 1.13. Текущая локальная парная
проверка нового селектора прошла на sing-box `1.14.4` (7 тестов и 2 подслучая);
unit-наборы приёмника и D6ton прошли: 23 теста и 47 подслучаев.
Историческая проверка на Dokimasia использовала Xray/REALITY; в этот раз стенд
не запускался и не перенастраивался. При повторении фиксируйте версию движка.
Первая версия переносит TCP. Упаковка UDP для
AWG/Hysteria, счётчики пользователей, управляющий канал и fallback на обычный
сайт ещё не реализованы. Публикация через Triodos, совместное использование
TCP/443 с сайтом и жизненный цикл приёмника требуют отдельной интеграции.
Единый SNI не гарантирует устойчивость к распознаванию или блокировке IP.
Штатные подключения официальных клиентов остаются без изменений.
