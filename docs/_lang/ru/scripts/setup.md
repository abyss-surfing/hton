# hton setup

Запускает настройку из настроенного целевого каталога, запрашивая недостающие параметры и секреты.

## Использование

```sh
./scripts/hton/setup [OPTIONS]
./scripts/hton/setup --help
```

Физический рабочий каталог должен совпадать с настроенной целью. Можно включить MTProto, Hysteria2 и собственный Outline WSS; точный список опций даёт `--help`.

## Платформа

Только Linux и macOS. Точка входа — Bash-скрипт; в Windows она недоступна.

## Скрипт проекта

[`scripts/setup`](../../../../scripts/setup)

## Настройка HTON в рабочем дереве Tartarus

Из корня Tartarus запустите `./hton/setup`, чтобы настроить серверный продукт
HTON и предложить загрузку отсутствующих серверных сервисов в
`hton/services/`. Скрипт вызывает `scripts/setup --section hton`; он не заменяет
эту команду установки HTON на сервер.
