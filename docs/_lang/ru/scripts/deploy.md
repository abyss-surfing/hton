# hton deploy

Копирует минимальный runtime-набор в настроенный целевой каталог без сборки и загрузки.

## Использование

```sh
./scripts/hton/deploy [--source-dir ABSOLUTE_DIR] [--dry-run] [--json] [--quiet] [--yes]
```

Копируются Python-установщик, shell-точки входа, документация оператора и закреплённый инвентарь образов. Изменяемое состояние и исходники full-R1 исключены. Доставка атомарна, `--dry-run` только показывает план.

## Платформа

Только Linux и macOS. Точка входа — Bash-скрипт; в Windows она недоступна.
