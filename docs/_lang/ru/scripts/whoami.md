# hton whoami

Показывает данные идентичности, DNS и сравнение локального и внешнего состояния только для чтения.

## Использование

```sh
./scripts/hton/whoami [--json]
```

## Платформа

Только Linux и macOS. Точка входа — Bash-скрипт; в Windows она недоступна.
