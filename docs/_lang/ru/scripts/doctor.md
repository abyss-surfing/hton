# hton doctor

Показывает локальные наблюдения о сервисах, runtime и Docker только для чтения.

## Использование

```sh
./scripts/hton/doctor [--json]
```

`--fix` и `--watch` объявлены, но не реализованы: возвращается структурированный результат о неполноте.

## Платформа

Только Linux и macOS. Точка входа — Bash-скрипт; в Windows она недоступна.
