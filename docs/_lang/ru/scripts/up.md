# hton up

Проверяет и запускает сохранённый включённый состав, включая автозапуск при загрузке.

## Использование

```sh
./scripts/hton/up [--json]
```

Образы не загружаются и не обновляются.

## Платформа

Только Linux и macOS. Точка входа — Bash-скрипт; в Windows она недоступна.
