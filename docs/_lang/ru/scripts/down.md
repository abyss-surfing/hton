# hton down

Останавливает все связанные компоненты, сохраняет намерение «остановлено» и отключает автозапуск.

## Использование

```sh
./scripts/hton/down [--json]
```

Ошибки собираются, поэтому команда продолжает работу и перечисляет выжившие компоненты.

## Платформа

Только Linux и macOS. Точка входа — Bash-скрипт; в Windows она недоступна.
