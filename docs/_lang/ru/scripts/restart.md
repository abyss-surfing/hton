# hton restart

Перезапускает указанные сервисы или все включённые дополнительные и data-сервисы, если имена не заданы.

## Использование

```sh
./scripts/hton/restart [SERVICE...] [--wait SECONDS]
```

Ожидание по умолчанию — 10 секунд.

## Платформа

Только Linux и macOS. Точка входа — Bash-скрипт; в Windows она недоступна.
