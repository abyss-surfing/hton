# hton remap-undo

Восстанавливает чужие контейнеры, перемапленные hton, по журналу ремапов.

## Использование

```sh
./scripts/hton/remap-undo [last|all|ID]
```

Восстановление учитывает дрейф и сохраняет исходные данные; без селектора требуется TTY.

## Платформа

Только Linux и macOS. Точка входа — Bash-скрипт; в Windows она недоступна.
