# hton usage

Печатает трафик Outline WSS по пользователям, собранный локальным коллектором метрик.

## Использование

```sh
./scripts/hton/usage [--json] [--collect]
```

`--collect` сохраняет новый замер без вывода. Запускать через sudo: защищённое состояние доступно только root.

## Платформа

Только Linux и macOS. Точка входа — Bash-скрипт; в Windows она недоступна.
