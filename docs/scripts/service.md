# hton service

Compatibility delegate to the modules, config and lifecycle commands.

## Usage

```sh
./scripts/hton/service ...
```

It carries no separate business logic; use `modules`, `config` or `up`/`down` directly.

## Platform

Linux and macOS only. The entry point is a Bash launcher and is not available on Windows.
