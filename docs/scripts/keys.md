# hton keys

Generate scoped release credentials and secrets.

## Usage

```sh
./scripts/hton/keys [KINDS...] [--device ID] [--show] [--force] [--json]
```

`--show` discloses credentials only with separate scoped authorization.

## Platform

Linux and macOS only. The entry point is a Bash launcher and is not available on Windows.
