# hton help

Print the command overview or help for a single command.

## Usage

```sh
./scripts/hton/help
./scripts/hton/help COMMAND
./scripts/hton/<name> --help
```

Help is side-effect free and exits 0.

## Platform

Linux and macOS only. The entry point is a Bash launcher and is not available on Windows.
