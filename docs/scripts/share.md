# hton share

Print client connection links, optionally as a QR code.

## Usage

```sh
./scripts/hton/share [IDENTITY] [--kind KIND]... [--target TARGET] [--client CLIENT] [--format text|json|qr] [--out FILE] [--json]
```

## Platform

Linux and macOS only. The entry point is a Bash launcher and is not available on Windows.
